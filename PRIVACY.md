# PromptDrawer privacy policy

Last updated: 1 November 2026

PromptDrawer is a browser extension that saves and improves prompts. It is built to keep your data on your device.

**What it stores.** Your saved prompts, folders, tags, settings, your optional "About me" text, an optional licence key and optional API keys. All of it is stored in Chrome's local extension storage on your computer.

**What it reads on web pages.** Only on chatgpt.com, claude.ai, gemini.google.com, perplexity.ai and copilot.microsoft.com, and only the text in the message box you are typing into (plus text you select when you use the right-click menu). It does not read the conversation, your account details or other pages.

**What it sends, and to whom.**
- Nothing, by default. There is no PromptDrawer server and no analytics.
- If you add your own API key and choose that engine, the rough prompt you ask to improve (and your "About me" text, if you turned that on) is sent to that provider only (Anthropic, OpenAI or Google), under their privacy policy.
- If you paste a Pro licence key, that key is sent to the licence server (Lemon Squeezy) to check it.
- Chrome's built-in AI engine, if you choose it, runs on your device.

**Permissions.** `storage` (save your prompts), `sidePanel` (the drawer), `contextMenus` (the right-click items), and access to the five chat sites above. Access to API providers and the licence server is optional and requested only when you turn those features on.

**Deleting your data.** Settings → "Delete all prompts and settings", or remove the extension. Both erase everything PromptDrawer stored.
